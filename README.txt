logo.png — Your exact uploaded official logo, unmodified

BEFORE YOU PUBLISH
1. Open config.js in a text editor.
2. Replace fictional Sample listings with real approved business names and offers.
3. Create two Google Forms: one for business enrollment, one for fundraising applications.
4. Paste their public response URLs into businessFormUrl and fundraiserFormUrl.
5. Decide and approve final featured sponsorship pricing/benefits and fundraising terms.
6. Remove or revise the 'Preview mode' notice in index.html once sample offers are replaced.
7. Preview the site on desktop and phone and test all links.

LOCAL PREVIEW
Double-click index.html to preview in a browser (internet connection helps load fonts).

PUBLISHING
Upload the five files together to a static host (for example GitHub Pages or Netlify).
Keep the published URL unchanged after printing the QR code.
For long-term portability, consider a custom subdomain (discounts.pwr-foundation.com)
if your domain provider permits DNS configuration. A custom subdomain requires setup.

UPDATING
Edit config.js, save, and republish the changed file. The URL stays the same.
This version does NOT automatically sync a Google Sheet. That can be added later.

IMPORTANT
- Demo businesses are fictional and NOT actual offers.
- Application buttons show a setup reminder until Google Form URLs are configured.
- Featured sponsorship payments are not yet collected through this site.
- This is a static site; it has no accounts, checkout, or card verification.
- Anyone can view the public offers; businesses must verify the physical card.

GITHUB PAGES: FIRST-TIME PUBLISHING (WEB BROWSER)
1. Create or sign in to a GitHub account at github.com.
2. Click + > New repository. Name it pwr-discount-card (or another available name).
3. Select Public, check Add a README file, then Create repository.
4. Open the repository and choose Add file > Upload files.
5. Open the extracted pwr-discount-site folder on your computer. Upload the six files INSIDE it, not the folder itself: index.html, styles.css, script.js, config.js, logo.png, README.txt.
6. Commit changes.
7. Go to Settings > Pages. Under Build and deployment select Deploy from a branch, main, /(root), then Save.
8. Wait for GitHub Pages to publish; the URL is typically https://YOUR-USERNAME.github.io/pwr-discount-card/ . Check the actual link in Settings > Pages.
9. Test on phone before generating a QR code. Avoid changing repository name or published address after printing.

UPDATES WITHOUT CHANGING QR
Open a file in GitHub, click the pencil icon to edit, then Commit changes. The same website address updates after redeployment. For new offers, edit config.js. To change colors/layout, edit styles.css.

IMPORTANT: A GitHub Pages repository using a free plan must generally be public. Never put private applicant data or confidential information in website files. Use Google Forms for applications. The current form buttons are placeholders until configured.
